MINIO SETUP GUIDE (LOCAL DEVELOPMENT)

This project uses MinIO Object Storage to store event images dynamically
for the homepage event gallery.

IMPORTANT NOTE:

The following files/folders are intentionally ignored in the Git repository
because they exceed GitHub's file size limits (100MB) and are runtime storage files.

Ignored files:
- minio.exe
- mc.exe
- data/

Each developer must download these files manually before running the project.

Download links:

MinIO Server:
https://dl.min.io/server/minio/release/windows-amd64/minio.exe

MinIO Client (mc):
https://dl.min.io/client/mc/release/windows-amd64/mc.exe

After downloading, place them inside the project folder:

rajbhasha_clone/
    minio/
        minio.exe
        mc.exe
        data/

Create the "data" folder manually if it does not exist.

--------------------------------------------------

STEP 1 — Start MinIO Server

Open a new terminal in VS Code.

Navigate to the MinIO folder inside the project:

cd minio

Example terminal path:

PS D:\New\rajbhasha_clone\minio>

Run the following command (IMPORTANT):

.\minio.exe server data --console-address ":9001"

You will see output like:

API: http://127.0.0.1:9000
WebUI: http://127.0.0.1:9001

Keep this terminal running while using the website.

--------------------------------------------------

STEP 2 — Run Django Server

Open another terminal in the project root folder and run:

python manage.py runserver

Open the website in your browser:

http://127.0.0.1:8000

Event cards and images will automatically load from MinIO.

--------------------------------------------------

STEP 3 — Access MinIO Web Console

Open the MinIO web console in your browser:

http://127.0.0.1:9001

Login credentials:

Username: minioadmin
Password: minioadmin

--------------------------------------------------

STEP 4 — Upload New Events

Inside the MinIO Web Console:

1. Open the bucket named:

events

2. Create a new folder for the event.

Folder naming format:

YYYY-MM-DD_event-name

Example:

2026-09-14_hindi-diwas
2026-08-25_rajbhasha-kirti-awards

3. Open the created folder.

4. Upload all event images inside the folder.

Example structure:

events/
    2026-09-14_hindi-diwas/
        img1.jpg
        img2.jpg
        img3.jpg

    2026-08-25_rajbhasha-kirti-awards/
        img1.jpg
        img2.jpg

--------------------------------------------------

STEP 5 — View Events on Website

After uploading images:

1. Refresh the homepage.
2. The new event card will automatically appear.
3. Clicking the event card will display all event images in the main carousel.

No code changes are required to add new events.
